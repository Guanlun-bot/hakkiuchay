      GitHub 金鑰

      金鑰只存在你這台裝置的瀏覽器，不會上傳到網站。做金鑰：New fine-grained token → Repository access 只選 hakkiuchay → Permissions 設定：
      Contents Read and write　Actions Read and write　Pages Read and write
      Sveltia 後台用的那把若權限夠，也可以直接用。
