      GitHub 金鑰

      到期前兩週，總控台與手機通知會提醒你換金鑰。換了新金鑰記得改這裡。

      金鑰只存在你這台裝置的瀏覽器，不會上傳到網站。做金鑰：New fine-grained token → Repository access 選 hakkiuchay 與 hakkiuchay-ops（書庫狀態） → Permissions 設定：
      Contents Read and write　Actions Read and write　Pages Read and write
      Sveltia 後台用的那把若權限夠，也可以直接用。
